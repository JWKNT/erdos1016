A graph is a set of dots, called vertices, joined by lines, called edges. A cycle is a closed path in a graph, and its length is its number of edges. A graph on \(n\) vertices is pancyclic if it has a cycle of every length from 3 to \(n\).

Erdős problem 1016 asks for the least number of edges of a pancyclic graph on \(n\) vertices. The answer is \(n + \log_2 n + \log^{*} n\), with an error of at most a fixed number of edges.

{{in-paper: Theorem 1.1 | 2}}

A cycle through all \(n\) vertices has \(n\) edges, so a pancyclic graph has at least \(n\) edges. Write \(n + h(n)\) for the least number.

Theorem 1.1

There is a fixed number \(A\) such that, for every \(n \ge 3\),

\[ \log_2 n + \log^{*} n - A \;\le\; h(n) \;\le\; \lfloor \log_2 n \rfloor + \log^{*} n + 1. \]

Here \(\log_2 n\) is the power of 2 that gives \(n\), so \(\log_2 1024 = 10\). The brackets \(\lfloor\;\rfloor\) round down to a whole number. The iterated logarithm \(\log^{*} n\) is the number of times that \(\log_2\) must be applied to \(n\) until the result is at most 1. From 65,536 the results are 16, 4, 2 and 1, so \(\log^{*} 65{,}536 = 4\).

For one million vertices, \(\log_2 n\) is about 19.9 and \(\log^{*} n\) is 5. So 25 edges above the million are enough, and at least \(24.9 - A\) are necessary.

The smallest cases are easy to try. A cycle on six vertices with one more edge is never pancyclic. With the right two edges it is, so \(h(6) = 2\).

{{in-paper: Section 1 | 1 ; Section 2 | 2}}

An even subgraph is a set of edges that meets every vertex an even number of times. A cycle is an even subgraph, and so is the empty set. A connected graph with \(e\) edges and \(v\) vertices has the rank \(r = e - v + 1\), and it has exactly \(2^{r}\) even subgraphs.

A pancyclic graph with \(n + h\) edges has the rank \(h + 1\), so it has fewer than \(2^{h+1}\) cycles. It needs \(n - 2\) cycles of different lengths. So

\[ n - 2 \le 2^{h+1} - 1, \qquad\text{and then}\qquad h \ge \log_2(n-1) - 1. \]

Bondy stated this in 1971.

This limit would be exact only if all cycles had different lengths. But many cycles of a graph have the same length, and that makes \(\log^{*} n\) more edges necessary.

{{in-paper: Proposition 4.1 | 5 ; Figure 2 | 6}}

The upper limit comes from one graph. Take a path on a long cycle, and divide it into \(k\) segments with 2, 3, 5, 9 and so on edges. Segment number \(i\) has \(2^{i} + 1\) edges, from \(i = 0\). Join the two ends of each segment by one new edge, a shortcut. A path that takes the shortcut of segment \(i\) is shorter by \(2^{i}\) edges.

Every number from 0 to \(2^{k} - 1\) is a sum of different powers of 2. So the paths through the \(k\) segments have \(2^{k}\) lengths in a row. In the example, one more edge closes these paths to cycles.

Four segments

The rest of the long cycle also closes these paths, and it gives the longest cycles, up to \(n\). With \(k\) about \(\log_2 n\), all lengths from \(k + 1\) to \(n\) are present. At most one length is an exception, and one more edge gives it.

The lengths from 3 to \(k\) are still missing. A second closing edge closes only the first \(\lceil \log_2 k \rceil\) segments, where the brackets round up. Their cycles reach past the length \(k\). Do the same for these first segments, until the length 3 is present. In total this takes \(\log^{*} k\) closing edges, and the graph has at most \(\lfloor \log_2 n \rfloor + \log^{*} n + 1\) edges above \(n\).

{{in-paper: Section 3 | 3}}

For the lower limit, measure how well a graph fills a run of cycle lengths. Suppose that a graph of rank \(r\) has a cycle of every length from 3 to \(L\). Its density is \((L-2)/2^{r}\): the number of these lengths, divided by the number of even subgraphs. Let \(\Phi(R)\) be the least upper limit of the densities of all graphs of rank at least \(R\).

By the count of cycles, \(\Phi(R) \le 1\). A pancyclic graph on \(n\) vertices with the rank \(r\) has \(n - 2 \le \Phi(r)\,2^{r}\). So a small \(\Phi(r)\) means a large rank, and the rank is \(h + 1\).

{{in-paper: Lemma 3.1 | 3 ; Lemma 2.2 | 3}}

Take a graph with a cycle of every length from 3 to \(L\). Build a subgraph \(W\) in steps. In each step, add a cycle of the least length that \(W\) does not have. Stop when the rank of \(W\) is at least \(2R\). Then \(W\) is a union of at most \(2R\) cycles, and its number \(m\) of edges is at most \(\Phi(R)\,2^{2R} + 2^{R} + 5R\).

For an even subgraph, the outside part is the set of its edges that are not in \(W\). A forest is a set of edges that contains no cycle. Look at a cycle \(C\) of the graph. If its outside part contains a cycle, that cycle is \(C\). If its outside part is a forest, then \(C\) has between 1 and \(m\) edges in \(W\).

So an outside part with a cycle belongs to one cycle length, and a forest belongs to at most \(m\) lengths. Let the graph have the rank \(r\), and let \(W\) have the rank \(t\). Then there are \(2^{r-t}\) outside parts. If the fraction \(p\) of them are forests, the number of cycle lengths is at most

\[ 2^{r-t}\,(p\,m + 1 - p). \]
{{in-paper: Proposition 3.2 | 4 ; Corollary 3.3 | 4 ; forest: Corollary 1.2 | 3}}

The forest estimate is a separate result. For a graph of large rank \(r\) and a subgraph \(W\) of this kind, it says that \(p\) is at most \(\frac12 + 20/\log_2\log_2\log_2 r\). With the count above, this gives for every large \(R\)

\[ \Phi\bigl(2^{256R}\bigr) \le \Bigl(\frac12 + \frac{20}{\log_2\log_2 R}\Bigr)\,\Phi(R) + 2^{2-R}. \]

So from the rank \(R\) to the rank \(2^{256R}\), the density falls by a factor of almost 2. Apply this again and again, along the ranks in the figure. The errors of all steps add up to a fixed number, so \(\Phi(R_j)\) is at most a fixed number times \(2^{-j}\). About \(\log^{*} r\) of these ranks are below \(r\). So \(\Phi(r)\) is at most a fixed number times \(2^{-\log^{*} r}\), and this gives the lower limit of the theorem.
