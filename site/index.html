An illustrated proof guide · October 2026

How few edges can hold
every cycle length?

A network can contain an enormous number of loops using surprisingly few connections. But containing a loop of every length costs something extra. That tiny extra cost is the heart of Erdős problem 1016.

No graph theory is assumed. We will build examples, turn loops into binary algebra, and follow the proof all the way from a probability estimate to the final bound.

This guide explains the proof in this repository. Its Lean theorem is unconditional; the linked source revision passed fresh verification. The experiments are finite illustrations, not substitutes for the proof. The asymptotic formula does not give exact small values.

1 · The object

One graph. Every possible loop length.

A graph is a set of vertices (dots) joined by edges (lines). Here graphs are simple: no edge joins a vertex to itself, and no pair of vertices has two edges between them. The geometry of the drawing does not matter; crossing lines do not create new vertices.

A path follows edges without repeating vertices. A graph is connected if a path joins every pair of vertices. Its connected components are the separate maximal connected pieces.

A cycle follows edges back to its starting vertex without visiting any other vertex twice. Its length is its number of edges, also its number of vertices. A graph on n vertices is pancyclic if it contains a cycle of each length 3, 4, …, n.

Start with one cycle through all the vertices. Such a cycle is called Hamiltonian; it ensures the graph is connected. Extra edges between its vertices are called chords. Which chords make all the shorter lengths appear?

Experiment · a six-vertex laboratory

Toggle chords, then choose a cycle length to trace an actual example. Missing lengths are reported explicitly.

Write the smallest possible edge count as n + h(n). The function h measures the excess over the n edges of a Hamiltonian cycle. The theorem says:

h(n) = log₂ n + log* n + O(1)

The notation O(1) means an error bounded by a fixed constant, independent of n. It does not mean “approximately one,” or a relative error. More generally, O(f(r)) means a quantity whose absolute size is at most a fixed constant times f(r), for all sufficiently large r. All logarithms below are base two unless written ln, which means the natural logarithm.

A logarithm reverses exponentiation: log₂ 8 = 3 because 2³ = 8. The iterated logarithm log* n counts how many repeated logarithms take n down to at most 1. Equivalently, define the towers T₀ = 1 and Tj+1 = 2Tj; log* n is the least j with n ≤ Tj.

Experiment · an extraordinarily slow function

Despite its slow growth, log* is unbounded. Proving that it genuinely belongs in the answer requires more than counting cycles.

2 · The upper bound

Binary choices build a whole interval

First show that the claimed number of edges is enough. An upper bound comes from constructing one successful graph. A lower bound, the harder direction here, must constrain every successful graph.

On a large cycle, take consecutive arc segments of lengths 2, 3, 5, 9, …, 2k−1 + 1. Add a one-edge shortcut across each segment. Choosing the shortcut instead of the original segment saves 1, 2, 4, 8, … edges. Every integer from 0 through 2k − 1 is a sum of a subset of those powers of two: this is binary notation in a graph.

Experiment · four switches, sixteen lengths

A closing edge joins the two ends of the arc. Choose which long segments to replace. The same graph contains every displayed choice.

The complete construction, including the small lengths

For n ≥ 7 choose the largest k with 2k + k + 1 ≤ n. Name the segment endpoints v₀, …, vk. The original arc has length 2k + k − 1. Add the k segment shortcuts and the closing edge v₀vk.

Traversing the arc and this closing edge gives all lengths [k + 1, 2k + k]. Traversing the arc and the other side of the original n-cycle gives [n − 2k + 1, n]. Maximality of k implies n ≤ 2k+1 + k + 1, so there is at most one length between these intervals. One chord of the original cycle supplies that length if necessary.

For example, n = 11 gives k = 2 and intervals [3, 6] and [8, 11]. The only gap is 7: connect vertices at distance 6 around the original cycle. For n = 16, k = 3 gives [4, 11] and [9, 16], leaving only length 3 below the intervals.

To fill the short end in general, start at t = k. While t > 2, put j = ⌈log₂ t⌉ and add v₀vj. The first j segments now give [j + 1, 2j + j], overlapping the coverage already established because 2j ≥ t. Replace t by j and repeat. The process reaches triangles and uses at most log* k − 1 further chords.

The ceiling ⌈x⌉ rounds up; the floor ⌊x⌋ rounds down. For 3 ≤ n ≤ 6, use the original cycle, the chord joining vertices 0 and 2 when n ≥ 4, and additionally 0–3 when n = 6. For the large case, the total added is at most k segment shortcuts + one closing edge + one gap repair + (log* k − 1) recursive chords, or k + log* k + 1. Since k ≤ ⌊log₂ n⌋ and log* k ≤ log* n, together these constructions give the explicit bound

h(n) ≤ ⌊log₂ n⌋ + log* n + 1.

The recursive short-end repair explains why a log-star term is plausible. It does not yet show that every other construction must pay that cost.

3 · The algebra underneath

Cycles behave like binary vectors

The degree of a vertex is the number of incident edges. In a cycle each used vertex has degree two. More generally, an even edge set selects edges so every vertex has even degree. It may be empty, or contain several cycles, or have vertices of degree four. It need not be a single cycle.

Add two edge sets by symmetric difference, or XOR: an edge survives exactly when it occurs in one set but not both. At each vertex, even plus even remains even. Thus all even sets form a binary vector space, called the graph’s cycle space. Its scalars are 0 and 1 with 1 + 1 = 0.

Experiment · four words, only two simple cycles

Two triangles sharing one vertex form a basis: independent on/off choices generate every even set. Selecting both makes an even set but not one simple cycle.

You can think of a cycle-space word as a binary codeword constrained by one parity check at each vertex. XOR adds valid codewords while keeping every check satisfied. A basis is a list of independent vectors that generates the space uniquely. A space with r binary basis vectors has exactly 2r elements. Here r is the cycle rank:

r = edges − vertices + connected components.
Why that dimension formula is true

A tree is a connected graph without any cycle; a forest is a graph without cycles, possibly disconnected. Choose a spanning forest: within each connected component, keep a tree reaching every vertex. If there are v vertices and c components, it has v − c edges.

Each remaining edge closes a unique cycle through the forest. These fundamental cycles are independent because each has its own non-forest edge. They generate every even set: XOR away its non-forest edges, leaving an even set contained in a forest. That remainder must be empty, since any forest containing an edge has a leaf, a vertex of degree one. There are e − (v − c) fundamental cycles, proving the formula.

A pancyclic graph is connected, so with n + h edges its rank is h + 1. It needs at least n − 2 distinct simple cycles, one per required length. Each is a nonzero cycle-space word, giving

n − 2 ≤ 2h+1 − 1
h ≥ log₂(n − 1) − 1.

This is the classical counting lower bound. It finds log₂ n, but loses the extra log* n.

4 · The quantity that shrinks

Count useful lengths per binary word

Simple cycles use only some of the available words. And different cycles can have the same length. The proof measures efficiency in filling a consecutive interval, rather than just having many cycles.

Suppose a graph of actual rank r contains lengths 3 through q. Its normalized length capacity is (q − 2)/2r. Define Φ(R) as the supremum (least upper bound) of this quantity over graphs whose actual rank is at least R.

Φ(R) = supr ≥ R (q − 2) / 2r   ≤ 1.

The denominator always uses the graph’s actual rank, not the cutoff R. Raising the cutoff excludes candidates, so Φ cannot increase. Disconnected realizers can be connected by bridges: a bridge joins components and creates no cycle, preserving both rank and the existing lengths.

The goal is Φ(r) ≤ C · 2−log* r for one fixed constant C. This says only a slowly diminishing fraction of binary capacity can be converted into a complete interval of lengths.

5 · The combinatorial hinge

A small witness records the easy lengths

Inside a graph that already contains a long consecutive interval, build a witness W: a union of selected cycles. Start empty. Find the least length ≥ 3 not already represented in W, take a cycle of that length from the host graph, and add its edges. Stop at the first rank crossing t ≥ 2R.

The new cycle is not contained in the old union, or its length would already be present. Since every old edge lies on a cycle, the addition raises the rank by at least one. It can raise it by more than one; the proof does not assume equality. Charge each step to the rank just before it. Skipped ranks incur no charge.

At preceding rank s, there are fewer than 2s represented lengths, so the least missing length is at most 2s + 2. Once s ≥ R, the definition of Φ improves this to Φ(R)2s + 3. Summing these geometric budgets for the same witness gives:

m ≤ 23R,   c ≤ 2R,
(m + 1)2−t ≤ Φ(R) + 21−R.

Here m is the number of witness edges, t its rank, and c its number of components. Count components only on vertices used by the witness, not isolated vertices elsewhere in the host.

Check the simultaneous witness budgets

There are at most 2R selected cycles because every preceding rank is a different integer below 2R. Their union has at most that many components. Charging the coarse length bound to all possible ranks gives m ≤ Σs=0,…,2R−1(2s + 2) = 22R + 4R − 1 ≤ 23R, for sufficiently large R.

Use the coarse bound only for s < R and the Φ-bound thereafter. With φ = Φ(R), this gives m + 1 ≤ φ22R + 2R + 5R. Because the stopping rank t is at least 2R, division by 2t yields (m + 1)2−t ≤ φ + 21−R, again for sufficiently large R. A rank jump skips terms in these sums and can only improve the bounds.

Why the restriction map turns this into a length bound

Let M be the edges outside W. Restrict each cycle-space word to M. This is a linear map. Its kernel, the words that restrict to the empty set, is exactly the cycle space supported inside W, of dimension t. Consequently there are 2r−t possible outside words and every one has exactly 2t preimages. This is why a uniform ambient word induces a uniform distribution on the image.

A simple cycle meeting both W and M leaves a forest outside: removing at least one edge from a simple cycle breaks its loop. For a fixed outside word, the number of inside edges can be only 0 through m, so at most m + 1 total lengths can occur. A cycle entirely outside contributes at most one length per outside word. Entirely inside cycles contribute at most m possible lengths.

If P is the probability that a uniform ambient even set restricts to a forest outside, counting these three kinds and dividing by 2r gives

(q − 2)2−r ≤ (m + 1)2−tP
+ 2−t + m2−r.

These categories may overcount lengths, which is harmless for an upper bound. The two final terms will be tiny at the scales used below. If the host interval was too short to finish the extraction, its normalized capacity is already below the recurrence’s error term.

The central mechanism is simple enough to see without the algebra: cut some edges out of a single loop and what remains has no loop. Such an edge set is a forest; the empty set counts, but a nonempty path counts too. Fixing the remaining edges fixes their length contribution, while the witness can add only 0 through m edges. That leaves at most m + 1 possible total lengths for the same outside pattern.

Experiment · cancel the diagonal, then cut the loop

These two triangles overlap on a diagonal. XOR cancels that shared edge. Mark one triangle as W, and inspect what survives outside it. With both basis cycles selected, the ambient word is a square but the outside restriction is a nonempty path.

Everything now depends on one question: how large can P be?

6 · The new estimate

Outside a small witness, forests are scarce

A forest is any edge set with no cycle, including the empty set. Choose a cycle-space word uniformly: flip independent fair bits for its basis vectors and XOR them. Do not flip an independent coin for each edge; that would usually violate even degrees. Do not choose a simple cycle uniformly either. Empty and multi-cycle even sets belong to this probability space.

Experiment · enumerate the probability space

Two triangles are joined by a bridge. Mark the left triangle as W. The bridge is absent from every even word. Exactly two of the four words leave a forest outside W.

A restriction need not itself have even degrees. For a square with diagonal 0–2, take W to be triangle 0–1–2. Restricting the square word to the complement leaves the path 2–3–0: a nonempty forest. This matters because “forest outside” is a much broader event than “empty outside.”

The forest estimate

For all sufficiently large ranks r, let G be connected and simple, and W a nonempty union of cycles with at most √r edges and at most (log₂ r)/100 components. Then

P(forest outside W) ≤ ½ + 20 / log₂ log₂ log₂ r.

The hypotheses are essential. Our tiny example illustrates the definitions and the half threshold; it does not test this large-rank theorem. For moderate numbers the right side can exceed 1, making the estimate uninformative. The proof is asymptotic, with a uniform sufficiently-large threshold.

Why one half? Parity can couple many distant regions through one shared binary choice. A proof pretending their cycle events were independent would miss that obstruction. The next four chapters show how the actual dependence is controlled.

7 · Dependence, exactly

A cut is a boundary through the graph

A region here is the induced graph on a vertex set: retain all edges whose two endpoints lie inside. Its cut δA consists of edges with just one endpoint inside. A zero-cut event means the random even set selects none of those boundary edges.

For disjoint connected regions A and B, contract each to one vertex. Contraction preserves the relevant projected cycle-space law. Define their links to be the direct edges between them plus the components left after deleting them that touch both. If there are ℓ links, rank subtraction gives an exact identity:

P(δA = δB = 0) / [P(δA = 0)P(δB = 0)]
= 2ℓ−1.

The notation δA = 0 describes the selected boundary edges; the original graph can still have a nonempty cut. The ratio measures correlation: 1 is independence, above 1 means simultaneous occurrence is more likely than the product predicts. With one link the ratio is 1, with two it is 2, and three gives 4. Pairs with at least three links are called exceptional.

Experiment · change the number of links

Each route has its own middle vertex. Explore every even word exactly; watch how the two boundary events stay tied together as links are added.

Why there cannot be many disjoint exceptional partners

Fix a region with cut size d. After contraction, append its d incident edges as terminal leaves to a spanning forest of the rest. Prune away branches containing no terminal. Three or more links to another contracted region require a branching point in this terminal forest. A forest with only d terminal leaves has at most d such branching points. Therefore a vertex-disjoint family of exceptional partners has size at most d.

Now take k disjoint connected cyclic regions, each with cut size at most d. The event “zero cut and nonempty inner even set” guarantees a cycle and has probability at least 2−d−1. Once the cuts are zero, inner even sets in distinct regions are independent; the dependence between the full events comes from their cuts. The exceptional-partner bound and the second-moment inequality from chapter 10 give

P(forest on their union) ≤ ½ + (d + 1)2d/(2k).

This small-cut estimate will be used twice: first to remove short cycles, then to limit cyclic links between retained cycles.

8 · Put the graph into a useful form

Simplify without losing the probability law

Assume, for contradiction, that the forest probability is larger than ½ + 20/z, where x = log₂ r, y = log₂ x, and z = log₂ y. Write ε = 20/z for the excess above one half. We will show this assumption cannot survive.

  1. Split high-degree vertices. Replace a vertex with many incident edges by a small tree whose new vertices have degree at most three. Contracting the tree reverses this operation and gives a bijection of cycle spaces. Keep the incidences belonging to W together and mark the corresponding connected pieces. The marked set P has at most 2m vertices and at most c components.
  2. Prune and suppress. Remove unmarked leaves: their edge is always absent from an even set. Replace unmarked degree-two paths by single edges: evenness forces all edges along such a path to have the same bit. Never remove a marked vertex. This can introduce loops or parallel edges; the auxiliary object is a multigraph, even though the original problem concerns simple graphs.
  3. Keep track of what is preserved. The resulting connected multigraph Γ has the same rank r, degree at most three, and all unmarked vertices have degree exactly three. Such vertices are called cubic. The probability of a forest off P is at least the original outside probability. Thus an upper bound for the transformed event proves the desired upper bound for the original one.

Here |Γ| and |J| count vertices in those graphs; for a cycle C, |C| will count its edges. The degree sum gives |Γ| = 2r − 2 + Σv(3 − degree(v)). Only marked vertices contribute a nonzero term, so |Γ| = 2r + O(√r).

Set D = ⌊x/10⌋. If there are at least ⌈√r⌉ vertex-disjoint cycles of length at most D outside P, their induced regions have cuts at most D. The small-cut bound forces the forest probability close enough to one half to contradict our assumption.

Otherwise choose a maximal packing of short cycles: a disjoint collection to which no further disjoint short cycle can be added. “Maximal” does not mean largest possible. Remove its vertex set S. Then |S| ≤ D√r, and J = Γ − (P ∪ S) has no cycles of length ≤ D.

The girth is the length of a shortest cycle. J has girth greater than D and is simple: loops and pairs of parallel edges would be cycles of lengths one and two. Removing vertices lowers neighboring degrees, so J is not necessarily cubic or even of positive minimum degree. Its degree deficit still obeys

dJ = Σu∈J(3 − degreeJ(u))
≤ 3(|P| + |S|) = O(√r log r).

It has about 2r vertices and only a small total deficit. That global fact, rather than a minimum-degree assumption, supplies the next step.

9 · From walks to actual cycles

A matrix counts walks that never turn straight back

A walk may revisit vertices. It is nonbacktracking if it never immediately reverses the edge it just took. Make each directed edge of J a state. The matrix B has entry 1 for an allowed next state and 0 otherwise. Matrix multiplication counts successive choices; the trace of Bℓ, the sum of its diagonal entries, counts closed nonbacktracking walks of length ℓ with a distinguished directed starting edge, including the no-backtrack condition at closure.

Experiment · a walk is not necessarily a cycle

Step along four routes: a simple triangle, a figure-eight with a repeated central vertex, a route that immediately retraces an edge, and one whose reversal occurs only where the end meets the beginning. The drawing is an illustrative degree-four graph, not the proof’s retained graph J. Only the first route is a simple cycle; the figure-eight explains why a matrix walk count needs a correction.

Near degree three, each incoming edge leaves almost two forward choices. One expects growth near 2ℓ. The proof makes that intuition precise despite missing degrees.

The spectral argument, with its objects defined

The adjacency matrix A has Auv = 1 when u and v are adjacent. The diagonal degree matrix Δ records each vertex’s degree. I is the identity matrix. Study the symmetric matrix M(t) = t²I − tA + Δ − I.

An eigenvector is a nonzero vector whose direction a matrix preserves; its multiplying factor is an eigenvalue. The smallest eigenvalue of the real symmetric M(t) varies continuously with t. At t = 2 the matrix is positive semidefinite, meaning every quadratic form uᵀMu is nonnegative: M(2) = 2(Δ − A) + 3I − Δ. The matrix Δ − A is called the graph Laplacian. Its quadratic form is Σedges uv(uu − uv)², a sum of squares; the diagonal entries of 3I − Δ are nonnegative because degrees are at most three. Thus both terms are positive semidefinite. Here uᵀ means the transpose of a column vector, turning it into a row.

At t = 2 − dJ/|J|, the quadratic form on the all-ones vector is zero. Thus the smallest eigenvalue is nonpositive there, and crosses zero somewhere up to 2. A null vector u of M(t) gives the nonzero B-eigenvector f(i,j) = tuj − ui. So B has a real eigenvalue close to 2.

For a nonreal eigenvalue t of B, the reverse construction gives a nonzero complex vector u with M(t)u = 0. Multiplying by its conjugate transpose u* gives a quadratic equation a t² − b t + c = 0 with real coefficients, a = u*u > 0 and c/a = u*(Δ − I)u/(u*u) ≤ 2. Its roots are the conjugate pair t and its conjugate, whose product is |t|² = c/a. Hence nonreal eigenvalues of B have magnitude at most √2. Even powers of real eigenvalues are nonnegative. Taking even ℓ therefore prevents harmful sign cancellation, and bounds the remaining complex contribution:

2−ℓ tr Bℓ ≥ (1 − dJ/(2|J|))ℓ
− 3|J| · 2−ℓ/2.

Let L = ⌊x√y⌋. Sum the normalized traces through length L, with weight 1/(2ℓ). A simple undirected cycle of length ℓ occurs 2ℓ times in the trace, once per start and orientation, so this divisor removes that overcount.

But a closed walk can repeat vertices. Here high girth earns its keep. Put s = ⌊(D − 1)/2⌋. Between fixed endpoints there is at most one nonbacktracking path of length s; two would create a cycle of length at most 2s < D. Branching-count bounds then make long returns rare. If Nt(u,w) counts nonbacktracking walks of length t between fixed endpoints and t > s, there are at most 3·2t−s−1 choices for the prefix and at most one length-s suffix to w. Therefore 2−tNt(u,w) ≤ (3/2)2−s.

Why the walk count really produces simple cycles

A nonsimple cyclically nonbacktracking walk contains a proper simple cycle. Encode the walk by that cycle, an oriented start, its complementary nonbacktracking walk, and the original root. The complement must be longer than D. Girth bounds the number of such complements, giving

0 ≤ T − V ≤ (3/2)L²2−sV,
T = Σℓ≤L tr Bℓ/(2ℓ2ℓ),
V = Σsimple C, |C|≤L 2−|C|.

The correction tends to zero. Summing even lengths from about 6x to L supplies T ≥ (1/8 + o(1)) ln y, hence the same lower bound for V. Here o(1) means a quantity tending to zero as r tends to infinity, uniformly over graphs satisfying the hypotheses.

Think of the trace as a fast counting instrument: it counts closed routes without listing every cycle. High girth lets us bound the instrument’s false positives, the routes that revisit vertices. After subtracting that controlled error, we really have many actual simple cycles in J in the weighted sense V → ∞. The weight 2−|C| compensates for longer cycles being harder to select. A large total weight alone is not enough: all the detections might be concentrated in a very small fraction of random words. We must show the cycle events do not cluster too strongly. That is the job of the next chapter.

10 · The probabilistic finish

Enough weight, with controlled dependence

For each retained cycle C, let IC be the event that C is a connected component of the ambient random even set. Because all its vertices have ambient degree three, selecting both cycle edges at each vertex forces the third edge absent. Write aC = 2−|C| and pC = P(IC).

Selecting C alone is an even word, so the constraints are feasible (at least one solution exists). Requiring its |C| edge coordinates to be 1 imposes at most |C| independent binary equations. Each independent equation halves the possible words, so pC ≥ 2−|C| = aC. Normalize the indicator by setting XC = (aC/pC)1IC. An indicator is 1 when its event happens and 0 otherwise. Then 0 ≤ XC ≤ 1 and its expectation (probability-weighted average) is aC. Let Z be the sum of the XC. It is a weighted detector of surviving cycles: if Z is positive, the outside set cannot be a forest. The normalization makes every cycle’s average contribution exactly its chosen weight, even when graph-wide constraints make its true selection probability larger. Its mean μ = E Z equals V.

A forest outside P requires Z = 0. The exact cut law says that for disjoint cycles,

E(XCXC′) = aCaC′2ℓ(C,C′)−1.
Control all the links, including the deleted regions

Classify components outside C ∪ C′ in the original Γ, not merely in the retained graph J. Components meeting P number at most c, since P has at most c connected components. The other components have cuts totaling at most 2L, the available external incidences on the cycles.

Choose t₀ = ⌊y/2⌋. There are at most 2L/t₀ components with larger cuts. Among the small-cut components, the cyclic ones number only O(t₀2t₀/ε), by the small-cut estimate and our contradictory assumption P > ½ + ε.

A remaining forest component is a tree and cannot meet S: if it met a deleted packed cycle, that entire cycle would lie inside the component, contradicting that it is a tree. Thus these forest components live in the high-girth J. Ambient degree three gives |F| = |δF| − 2. Each small-cut forest link yields a short joining path between C and C′.

Partition each cycle into blocks of at most ⌊D/4⌋ consecutive vertices. Two joining paths attached to the same pair of blocks would create a cycle shorter than D. There are only O((L/D)²) block pairs, so

ℓ(C,C′) ≤ c + O((L/D)² + L/t₀ + t₀2t₀/ε)
= c + o(x).

This is why controlling the witness’s component count mattered all along. Bounding only the number of marked vertices would be too crude.

Nonexceptional disjoint pairs contribute at most 2aCaC′. Distinct intersecting cycles cannot both be components of the same even set, so contribute zero. Exceptional partners have a disjoint packing of at most L members; its union has at most L² vertices and meets every exceptional partner. The high-girth return estimate bounds cycle weight through each such vertex. Combined with the link bound, the total exceptional contribution for a fixed C is o(1)aC: the factor 2c+o(x) is beaten by 2−s, since c ≤ x/100 while s ≈ x/20. More explicitly, cycle weight through one vertex is O(L2−s), so the row of exceptional pair contributions is at most aC·2c+o(x)·O(L³2−s) = o(1)aC. Powers of L grow only polynomially in x and √y, while the negative exponential has a fixed linear margin in x.

Putting diagonal terms and all pairs together yields the second moment, the average of Z²:

E Z² ≤ 2μ² + (1 + o(1))μ.

The Cauchy–Schwarz inequality applied to Z and the indicator of Z > 0 gives (E Z)² ≤ E(Z²)P(Z > 0). More generally, if E Z² ≤ 2μ² + Kμ, then

P(Z = 0) ≤ 1 − μ²/E Z²
≤ ½ + K/(4μ + 2K).

Experiment · why more cycle weight helps

Hold K = 1 fixed and vary μ. This shows the algebraic inequality, not measured graph probabilities. It approaches one half rather than zero because pair contributions may be twice their independent value.

Since μ ≥ (1/8 + o(1)) ln y, we obtain P(forest outside P) ≤ ½ + (2 + o(1))/ln y < ½ + 20/z for sufficiently large r. That contradicts the assumption made in chapter 8, proving the forest estimate.

11 · Close the loop

One halving for each exponential scale

Return to the witness. At host rank r ≥ 2256R, its bounds m ≤ 23R and c ≤ 2R fit inside √r and (log₂ r)/100. Substitute the forest estimate into the restriction count, and use the witness’s weighted budget. The result is the proof’s recurrence, a bound at one scale in terms of an earlier scale:

Φ(2256R) ≤ (½ + 20/log₂ log₂ R)Φ(R)
+ 22−R.

It is not exact halving. The coefficient approaches one half and the additive error approaches zero. Those errors must be controlled over all iterations, not merely ignored.

Why infinitely many errors do not accumulate disastrously

Choose a sufficiently large fixed R₀ and define Rj+1 = 2256Rj. Then log₂ log₂ Rj = 8 + 256Rj−2 for j ≥ 2. These denominators grow so rapidly that the sum of their reciprocals converges. The additive errors, after multiplying by the compensating factors 2j, also have a finite sum.

Multiplying the recurrence by 2j+1 gives a sequence whose multiplicative factors are 1 plus a summable error and whose additive errors are summable. Their products and accumulated contributions remain bounded. Thus Φ(Rj) = O(2−j).

The tower Rj grows by one exponential level each step: log* Rj = j + O(1). The factor 256 changes this relation by only a bounded offset, not by a new factor in j. Here is a concrete comparison. Choose an ordinary tower U₀ = Ta so large that R₀ ≤ √U₀ and √U₀ ≥ 512, and put Uj+1 = 2Uj. If Rj ≤ √Uj, then 256Rj ≤ Uj/2, so Rj+1 ≤ √Uj+1. Induction gives log* Rj ≤ a + j. Conversely R₀ ≥ 1 and Rj+1 ≥ 2Rj give Rj ≥ Tj, hence log* Rj ≥ j.

For a rank r between Rj and Rj+1, monotonicity gives Φ(r) ≤ Φ(Rj) = O(2−j), while log* r ≤ j + 1 + a. The fixed offset is absorbed into the constant, giving Φ(r) = O(2−log* r).

Experiment · the shape of the recurrence

This deliberately idealized model sets the error terms to zero. Each step adds an exponential level and halves capacity. The real proof above is what justifies keeping this pattern despite errors.

Finally, for a pancyclic graph r = h + 1 and q = n. The capacity bound gives

n − 2 ≤ C · 2r−log* r,
r ≥ log₂(n − 2) + log* r − log₂ C.

The elementary cycle count also gives n ≤ 2r+1, hence log* n ≤ log* r + 2. Replace log* r by log* n − 2 and r by h + 1. The difference between log₂(n − 2) and log₂ n is bounded for n ≥ 3. All fixed losses fit into one additive constant A:

log₂ n + log* n − A ≤ h(n)
≤ ⌊log₂ n⌋ + log* n + 1.

The upper construction and the universal lower bound meet to within a bounded number of edges. That proves the claimed formula from start to finish.
