# Archived formalization and papers

This directory preserves the previous Lean formalization and its original paper.
It is excluded from the current library and CI theorem verification. The original
project README is preserved as `README.md`; its live CI badge refers to the current
repository, not to a fresh check of this archive.

- [Previous published paper](paper/erdos1016.pdf) and [LaTeX source](paper/erdos1016.tex).
- [Previous Lean endpoint](Erdos1016/Main.lean), with its original toolchain, dependency lockfile, audits, and verifier.
- [Shorter-proof draft supplied during development](drafts/erdos1016_shorter.pdf). This is an archived working draft, not an updated paper accompanying the current formalization.

The original source snapshot was taken at repository commit
`f035bc7e02de243d88443e65ef206b659040789d`. `ARCHIVE_MANIFEST.json` records the
hashes of the archived files published here. The website, generated previews,
local verification logs, and migration journals are preserved separately on the
owner's computer.

Use the root [README](../README.md) for the current theorem and verification instructions.
